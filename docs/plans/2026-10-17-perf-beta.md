# Performance beta implementation plan

> **For agentic workers:** Use subagent-driven execution for the independent
> cache task and inline execution for scheduler work. The superpowers
> execution skills mentioned by writing-plans are not installed; use the
> available tools directly. Track completed work below.

**Goal:** Build 0.9.11-beta.1 with bounded recovery and declaration reuse.

**Architecture:** Preserve the existing scheduler and its safety gates. A
single conservative recovery draw can replace a stale learned floor only
after 300 eligible frames. Independently replace permanent declaration-cache
exhaustion with bounded LRU replacement at group boundaries.

**Tech Stack:** Freestanding C, WinLibs i686 GCC, native test harnesses/D3D9.

## Global constraints

Follow the approved spec in `docs/specs/2026-10-17-perf-beta-design.md`.
No camera, logic, network, input, frame-limit, x87 or MXCSR changes.
No unlocker, reference-repo or installed-file modifications. Commit locally;
the request to push the baseline does not authorize publishing the new beta.

## Task 1: scheduler and diagnostics

- [x] Add transient-stall and persistent-expensive-draw regressions in
  `perf/tests/test_fps.c`, including interruption and clock wrap coverage.
- [x] Implement in `perf/src/fps.c`: count consecutive eligible frames;
  calculate `probe_cost = max(2 * regular_cost, PF_FPS_MIN_COST_US)`;
  require `pf_fps_schedule` to accept one draw with existing margins.
  Never modify the persistent floor until that draw succeeds. Count late
  probes toward escalation and stop after repeated failed recovery probes.
- [x] Expose per-row block counts, learned floor and probe results through
  `perf/src/fps.h`, `timing.c`, `csvrow.h` and `csvrow.c`; append columns and
  extend exact row-format expectations in `perf/tests/test_row.c`.
- [x] Run `mingw32-make build/test_fps.exe build/test_row.exe` then both
  executables. Existing safety, interpolation and scheduling tests must pass.

## Execution results

variants on native D3D9 and DXVK, with no skipped test groups. The load
banner assertion was updated for the prerelease version. The transient
regression failed on baseline and passes with recovery; persistent expensive
probes trigger a rest. Both native version strings report 0.9.11-beta.1 and
the Windows resource is flagged prerelease. Runtime files remain uninstalled.

The independently implemented cache task received parent review; its agent
also reviewed the recovery diff. No blocking issue remained. Larger render
