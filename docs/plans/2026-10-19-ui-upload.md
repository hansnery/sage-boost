# UI Vertex Upload Screen Implementation Plan

**Goal:** Determine whether combining UI vertex uploads can reduce complete
frame cost without changing UI drawing or its surrounding updates.

**Architecture:** A standalone owned D3D9 fixture compares direct per-request
locks with per-batch CPU staging and upload. Native and DXVK use the same
generated inputs, pixel/state checks and timing loops. Execute inline under
Hans's standing preapproval; no delegation or game launch.

**Tech Stack:** C, WinLibs i686, D3D9 COM, Python report parsing.

## Constraints

- Preserve beta.18 and installed INI bytes; public releases stay unchanged.
- Reference checkout and EA files remain read-only. Only generated assets run.
- Preserve request order, fresh geometry, all state boundaries and output.
- Native and DXVK completed-work results remain separate from gameplay FPS.
